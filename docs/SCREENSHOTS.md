# 📸 Инструкция по скриншотам для портфолио

## Подготовка

1. Запустите демонстрационную базу:
   ```powershell
   .\install_demo.bat
   .\start_demo.bat
   ```

2. Откройте в браузере `http://127.0.0.1:8000/`

3. Войдите с учётными данными:
   - **Логин:** `demo`
   - **Пароль:** `demo12345`

4. Откройте DevTools (`F12`) → переключите режим `Ctrl+Shift+M` → выберите **Desktop 1440×900**.

## Какие скриншоты сделать

Для портфолио достаточно **двух** снимков, демонстрирующих ключевые функции учётной системы.

### 1. Расчётные остатки
**URL:** `http://127.0.0.1:8000/records/stock/`

**Что должно быть видно:**
- Таблица с расчётными остатками (место хранения, товар, партия, срок годности, количество)
- Поле поиска (можно ввести пустое или `SAND-CHICKEN`)
- Пагинация внизу таблицы

**Совет:** используйте поиск по SKU `SAND` чтобы увидеть только хлебцы — таблица будет компактнее.

**Имя файла:** `01-stock.png`

---

### 2. Импорт продаж
**URL:** `http://127.0.0.1:8000/imports/sales/`

**Что должно быть видно:**
- Форма выбора поставщика и загрузки файла
- Таблица истории импортов со статусами

**Совет:** попробуйте загрузить `samples/demo_sales.csv` — он появится в истории с зелёным статусом «Импортирован».

**Имя файла:** `02-import.png`

---

## Сохранение

1. Сохраните скриншоты в папку `docs/screenshots/`:
   - `docs/screenshots/01-stock.png`
   - `docs/screenshots/02-import.png`

2. Формат: **PNG**, не сжимайте.

3. Убедитесь, что на скриншотах **не видно** пароля в адресной строке и URL `127.0.0.1:8000`.

> ⚠️ На всех скриншотах отображаются **демонстрационные (синтетические) данные**. Это не реальные продажи или финансовые показатели.

# История изменений

## v0.2.0 — серверный пилот (2026-09-17)

- Сохранены модели и расчёты v0.1.2; новые миграции БД не требуются.
- Режим production: PostgreSQL, индивидуальный секрет, явные домены, HTTPS.
- Отдельные вход, выход через POST и смена пароля владельца.
- Страницы просмотра холодильников, товаров, остатков, партий, продаж,
  списаний и пополнения с поиском и постраничным выводом.
- Фильтрация по активной организации; импорт и расчёт — владелец/оператор.
- Серверная admin только для superuser; у владельца нет таких прав.
- bootstrap_pilot на пустой базе: личный пароль, отключённый demo.
- Compose: PostgreSQL, Gunicorn, Nginx HTTPS, ежедневные резервные копии.
  Порт привязан к 127.0.0.1; публикации в интернете нет.
- Скрипт проверки восстановления в новую временную БД.
- Django 5.2.17, серверные зависимости без pytest/ruff.
- Сборщик ZIP исключает TLS-ключи, базы, секреты и кэши.
- Проверки Docker/PostgreSQL/TLS на целевом VPS остаются обязательными.

## v0.1.2 — 2026-09-17

### Демонстрационная база

- добавлена расширенная демонстрационная база на 7 холодильников;
- создано 4100 синтетических продаж за 60 дней;
- добавлены партии, остатки, списания и рекомендации по пополнению.

### Исправления

- исправлен повторный вывод рекомендаций: повторный расчёт пополнения больше не создаёт дубли.

### Интерфейс

- русифицирована административная панель.

### Зависимости

- разделены зависимости веб-системы (`requirements-web.txt`) и Telegram-бота (`requirements-bot.txt`);
- добавлена поддержка Python 3.12–3.14 для веб-системы.

### Установка и поставка

- добавлены `install_demo.bat`, `start_demo.bat` и инструкция владельца `START_HERE.md`;
- `install_demo.bat` выполняет `collectstatic`, поэтому `staticfiles` создаётся автоматически;
- добавлена безопасная сборка поставочного ZIP (`scripts/build_release.ps1`) без `.venv`, `db.sqlite3`, `.env`, кэшей и пользовательских данных.
